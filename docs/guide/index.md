# 快速开始

Semi 是可通过插件扩展的桌面设备管理应用，支持 macOS 和 Windows。你可以管理小米路由器、绿联云 NAS 和米家智能设备。

## 下载安装

前往[下载页面](/download)，选择与你的电脑对应的安装包，安装后启动 Semi。

## 添加设备

在设备看板中添加设备，并按照提示选择连接方式、填写所需信息。保存后应用会尝试连接设备。已添加的设备和连接状态会显示在看板中。

## 探索功能

连接成功后，可查看设备状态和统计数据，并执行该设备支持的操作，例如修改路由器网络设置或重启 NAS。也可以从「实用工具」的「发现」安装音频互联等插件。

不同型号和固件支持的功能可能不同。更多信息见[设备与连接](/guide/devices)。
