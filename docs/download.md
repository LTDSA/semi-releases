# 下载 Semi

选择适合你的电脑的安装包。所有版本和更新说明均发布在 Semi 的 GitHub Releases 页面。

## macOS

- **Apple Silicon**：选择文件名含 `macOS-arm64` 的 DMG。
- **Intel**：选择文件名含 `macOS-x64` 的 DMG。

## Windows

- **Windows x64**：选择文件名含 `Windows-x64` 的安装程序。

[前往下载最新版本 ↗](https://github.com/LTDSA/semi-releases/releases/latest)

[查看所有版本与更新说明 ↗](https://github.com/LTDSA/semi-releases/releases)

下载安装后，可参考[快速开始](/guide/)连接设备。
